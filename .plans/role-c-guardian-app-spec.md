# 角色 C：监护人端

端到端目标：一台真手机放在 iPad 旁边，第二幕诈骗时 2 秒内跳出红色等级卡片，第四幕 Memory 建立时出现普通卡片。平时负责人只看到老人允许看的东西。接口按 `shared-contracts.md`。

## 交付

1. 手机宽度网页（PWA，可装到桌面），HTTPS。通知靠 WebSocket 实时刷新，不依赖系统推送。
2. 设置页（一开始的设置，负责人做一次）：隐私信息（姓名、地址、电话）、支付方式（卡尾号、卡属于老人还是负责人、每月大概花多少作为基线）、产品信息（拍一张照片 + 写一句奶奶怎么叫它，调 `PUT /api/settings` 和货架 alias）、家庭照片上传、分享层级（三选一，默认「总数 + 异常」）、唤醒名字只读显示。
3. 首页：今天的用药提醒和待签收条目（普通卡片）；红卡置顶带「Call」和「Got it」按钮，用中性色不用红色；黄卡累计达 2 条才出现；单条黄只在时间线留灰字。
4. 账本页：按 `share_level` 显示。minimum 只有异常；default 多一个本月总数；open 有每一笔。卡片里附 `grandma_note`，没有时显示「Grandma didn't want to explain this one」。
5. Memory 页：列表、暂停、删除、改时间（`PUT /api/memories/:id`），改完显示「等奶奶重新确认」。
6. 提醒页：所有 Alert 历史，归档按钮。

## 验收

- 周六 14:00：和 B 一起把 `shared-contracts.md` 定稿。
- 周六 18:00 门禁：第二幕里手机在 2 秒内出现红卡，点「Got it」归档。
- 周日 01:00：第四幕 Memory 普通卡片出现；设置页能改分享层级并立即影响账本页。
- 断网重连后页面自动拉一次全量数据，不需要刷新。

## 依赖和边界

- 不做任何判断逻辑，级别、过滤都是后端给的。
- 需要 B 的 `/ws` 和 REST；需要 D 提供一组演示用的假数据（3 条订单、1 条 Memory、1 条红卡）方便离线开发。

## 砍法

Memory 页 → 提醒页 → 设置页只留分享层级和卡尾号。首页和红卡不能砍。
